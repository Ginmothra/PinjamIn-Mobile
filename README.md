# PinjamIn Mobile - Project Setup

Project ini dibangun menggunakan **React JS** dan **Vite** dengan fokus pada antarmuka pengguna (UI) yang premium dan responsif untuk perangkat mobile.

## Fitur Utama
- **Modern UI**: Desain dark mode yang bersih menggunakan Vanilla CSS.
- **Fast Performance**: Menggunakan Vite untuk development yang sangat cepat.
- **SEO Optimized**: Sudah dilengkapi dengan meta tags dan struktur HTML semantik.
- **Glassmorphism**: Efek kartu transparan yang memberikan kesan premium.

## Cara Menjalankan Project

1. **Install Dependensi** (jika belum):
   ```bash
   npm install
   ```

2. **Jalankan Server Development**:
   ```bash
   npm run dev
   ```
   Aplikasi akan tersedia di `http://localhost:5173/`.

3. **Build untuk Produksi**:
   ```bash
   npm run build
   ```

## Struktur Folder
- `src/index.css`: Berisi semua desain sistem dan variabel warna.
- `src/App.jsx`: Komponen utama aplikasi.
- `index.html`: Konfigurasi SEO dan Google Fonts.
